
Personal Firewall using Python

Project Description

This project demonstrates the development of a Personal Firewall application using Python in the Kali Linux environment. The application provides a simple command-line interface that allows users to simulate firewall operations such as blocking and allowing IP addresses. The project was developed to understand the basic concepts of network security, firewall functionality, and Python programming.

Tools Used

• Kali Linux
• Oracle VirtualBox
• Python 3
• Terminal
• iptables

Project Environment

Host Operating System : Windows 11

Virtual Machine : Oracle VirtualBox

Guest Operating System : Kali Linux

Programming Language : Python 3

Firewall Utility : iptables

Project Features

• Menu-driven interface
• Block an IP Address
• Allow an IP Address
• User-friendly command-line interaction
• Exit option to terminate the application

Implementation Steps

1. Created the Personal_Firewall_Project directory.
2. Verified Python installation in Kali Linux.
3. Developed the firewall.py program using Python.
4. Executed the application using the Python interpreter.
5. Tested the Block IP Address functionality.
6. Tested the Allow IP Address functionality.
7. Successfully exited the application.

Project Outcome

The Personal Firewall application was developed and executed successfully. The application accepted user input, performed the selected firewall operations, displayed appropriate confirmation messages, and terminated successfully after selecting the exit option. This project provided practical knowledge of Python programming, Linux command-line operations, and the basic concepts of firewall implementation.
